Cache Concepts (RFC 2616)

  • Cache: A local store of response messages that reduces response time and network bandwidth by reusing stored responses.
  • Freshness: A response is fresh if its age hasn't exceeded its freshness lifetime and can be served without contacting the origin server.
  • Validation: The process of checking with the origin server whether a cached response is still valid using validators like ETags or Last-Modified dates.
  • Expiration: The time specified by the origin server after which a cached response should not be returned without further validation.
  • Cache-Control: An HTTP header that transmits directives to control caching behavior and override default caching algorithms.
